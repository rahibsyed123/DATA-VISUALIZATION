# Titanic Dataset Data Visualization

## Project Overview
This project was completed as part of the CodeAlpha Data Analytics Internship. The goal of this task was to transform raw Titanic dataset information into meaningful visualizations for better understanding and analysis.

---

## Objectives
- Create meaningful visual representations
- Analyze passenger demographics visually
- Understand survival trends using charts
- Improve data interpretation using graphs

---

## Dataset Used
Titanic Dataset

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Visualizations Created
- Gender distribution bar chart
- Age distribution histogram
- Survival percentage pie chart
- Fare distribution boxplot
- Survival by gender countplot
- Passenger class distribution chart

---

## Files Included
- Visualization.ipynb
- titanic.csv
- README.md

---

## Conclusion
The project successfully converted raw data into visual insights using different plotting techniques and helped in understanding patterns within the Titanic dataset.
